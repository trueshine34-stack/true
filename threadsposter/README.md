# Threads Poster — автопостинг, поиск и ответы в Threads

Android-приложение (APK): само пишет и публикует посты в Threads, ищет чужие посты по
ключевым словам, оценивает их через DeepSeek и готовит осмысленные комментарии, а также
отвечает на комментарии под вашими постами.

Готовый APK: [`release/threadsposter-1.0.0.apk`](release/threadsposter-1.0.0.apk)
(~2 МБ, Android 8.0+).

Приложение-сосед для Telegram — [`../tgposter`](../tgposter).

## Что умеет

**Аккаунты**
- Несколько аккаунтов Threads одновременно, у каждого свои настройки.
- Долгоживущий токен (60 дней) продлевается автоматически — заново авторизовываться не нужно.
- Вход в одно нажатие через встроенный браузер либо вставка готового токена.

**Автопостинг**
- Инструкция для нейросети под каждый аккаунт: о чём, для кого, структура поста, чего избегать.
- Мастер инструкции: коротко описываете аккаунт — DeepSeek пишет полноценное ТЗ.
- Рубрики с весами и учётом давности, память последних тем — лента не повторяется.
- Расписания: по конкретным временам или с интервалом внутри окна, по дням недели,
  со случайным разбросом ±N минут, в часовом поясе аккаунта.
- Длинный текст уходит цепочкой постов с нумерацией 1/2, 2/2 — Threads держит только 500 символов.
- Режим модерации, разовые посты вне расписания, редактирование и перегенерация.
- Картинка по прямой ссылке.

**Поиск**
- Сохранённые поисковые запросы с собственным интервалом проверки.
- Грубые фильтры до обращения к модели: минимальная длина, стоп-слова, пропуск веток обсуждений.
- Пакетная оценка релевантности через DeepSeek: каждый пост получает балл 1–10 и объяснение.
- Порог отсечения задаёте вы — ниже порога пост просто не попадает в работу.

**Ответы**
- Черновик комментария готовится только для постов выше порога.
- Модерация: ничего не уходит, пока вы не подтвердите (по умолчанию включена).
- Ответы на комментарии под вашими собственными постами.
- Защита от навязчивости: пауза между ответами, дневные лимиты, одному автору не чаще
  раза в неделю, случайная задержка перед отправкой.

**Эксплуатация**
- Два рубильника: «Автопилот» и отдельно «Поиск и ответы».
- Уведомления об ошибках и о том, что ждёт подтверждения.
- Журнал событий с экспортом, автоочистка старых записей.
- Экспорт/импорт всей конфигурации в JSON.
- Работа только по Wi-Fi, восстановление расписания после перезагрузки.

## Как это работает внутри

```
                    ┌──────────────────────────────────────┐
                    │  AutopilotWorker (каждые 15 минут)   │
                    └───────────────┬──────────────────────┘
                                    │
     ┌──────────┬──────────┬────────┴───────┬─────────────┬────────────┐
     ▼          ▼          ▼                ▼             ▼            ▼
TokenKeeper  QueuePlanner  ContentGenerator  Publisher  LeadFinder  InboxWatcher
продление    расписание →  DeepSeek: посты,  Threads    поиск →     комментарии
токенов      слоты в БД    оценки, ответы    Graph API  оценка →    под своими
                                                        черновик    постами
```

**Цикл поста:**

```
QUEUED ──генерация──► READY ──────время публикации──────► PUBLISHED
   │                    ▲
   │                    │ подтверждение
   └──генерация──► NEEDS_APPROVAL
```

**Цикл находки:**

```
поиск ──► NEW ──оценка ниже порога──► SKIPPED
           │
           └──оценка выше порога──► черновик ответа ──► DRAFTED ──ваше «Отправить»──┐
                                                                                    ▼
                                            (без модерации: сразу) ──────────► QUEUED ──► REPLIED
```

Порядок в поиске выбран ради экономии: сначала бесплатные фильтры, потом одна пачечная
оценка сразу на десяток постов, и только для прошедших порог — отдельная генерация ответа.
Так на модель уходит малая часть найденного.

**Публикация в Threads двухшаговая:** сначала создаётся медиа-контейнер, потом он
публикуется. Между шагами есть пауза — без неё контейнер с картинкой регулярно не
успевает обработаться на стороне Meta.

**Про точность времени.** Android не даёт фоновым задачам гарантии «секунда в секунду»:
в глубоком сне публикация может сдвинуться на несколько минут. Для автопостинга это
незаметно, а разброс ±минут делает сдвиг вообще неотличимым. Чтобы сдвиг был минимальным,
отключите оптимизацию батареи (Настройки → Автопилот → «Настройки батареи»).

## Установка APK

1. Скачайте [`release/threadsposter-1.0.0.apk`](release/threadsposter-1.0.0.apk) на телефон.
2. Откройте файл — Android попросит разрешить установку из этого источника.
3. При первом запуске разрешите уведомления.

Требования: Android 8.0 (API 26) и выше. Приложение ставится рядом с Telegram-версией и
не конфликтует с ней.

APK подписан ключом разработки из репозитория (`signing/dev-signing.jks`, пароль
`threadsposter`) — чтобы новые сборки ставились поверх старых как обновление. Ключ не
секретный: для публикации в сторах заведите свой.

## Подключение аккаунта Threads

Threads пускает сторонние приложения только через приложение Meta — это не прихоть
приложения, а требование платформы. Один раз придётся пройти этот путь.

### 1. Создайте приложение Meta

На [developers.facebook.com](https://developers.facebook.com) → «Мои приложения» →
«Создать приложение» → выберите сценарий использования **Threads API**.

### 2. Включите права

В настройках Threads API добавьте разрешения:

| Разрешение | Зачем |
|---|---|
| `threads_basic` | обязательно для любых вызовов |
| `threads_content_publish` | публикация постов |
| `threads_read_replies` | чтение комментариев под вашими постами |
| `threads_manage_replies` | ответы на комментарии |
| `threads_keyword_search` | поиск по ключевым словам |

Без `threads_keyword_search` работать будет всё, кроме поиска.

### 3. Получите токен

**Путь А — вставить готовый токен (рекомендуется).** Получите долгоживущий 60-дневный
токен своего аккаунта в панели Meta и вставьте его в приложении: Аккаунты → **+**.
Дальше приложение продлевает токен само — для продления секрет приложения не нужен.

**Путь Б — вход в одно нажатие.** Настройки → «Приложение Meta» → впишите App ID,
App Secret и Redirect URI (тот же, что в настройках приложения Meta). Затем
Аккаунты → «Войти через Threads». Страница по Redirect URI открываться не будет —
приложение перехватит переход и заберёт код авторизации.

Путь Б удобнее, но требует хранить App Secret на телефоне. Meta прямо говорит, что
секрет должен жить на сервере, а не в клиенте. Приложение шифрует его ключом из Android
Keystore, но безопаснее всё же путь А: секрет не покидает вашего компьютера, а телефон
получает только токен.

### 4. Проверьте

На карточке аккаунта нажмите «Проверить» — приложение подтянет username и
threads-user-id. Потом Настроить → «Опубликовать тестовый пост».

## Настройка аккаунта

Экран аккаунта разбит на вкладки.

### Контент

**Инструкция аккаунта** — главный текст, по которому пишутся посты. Пример:

```
Пишу про поиск клиентов на фрилансе. Аудитория — дизайнеры и разработчики,
которые умеют делать работу, но не умеют себя продавать.

Каждый пост — одна конкретная мысль из практики: что сработало, что нет, почему.
Первая строка цепляет и не является вопросом. Дальше 2-3 коротких абзаца.

Без мотивационных лозунгов, без «успешного успеха», без обещаний дохода.
Не советую конкретные биржи и не рекламирую курсы.
```

Не хочется писать — кнопка «Сгенерировать инструкцию через DeepSeek»: опишите аккаунт
одной фразой, модель развернёт это в ТЗ, которое можно поправить.

**Стиль**: аудитория, тон, язык, диапазон длины, уровень эмодзи, режим длинных постов.

**Обвязка**: хэштеги, призыв к действию, подпись, стоп-темы, дополнительные правила.

**Модель и публикация**: модель DeepSeek, температура, кто может отвечать на ваши посты,
модерация, за сколько минут генерировать заранее, сколько последних тем помнить.

### Ответы

Включение ответов на комментарии под своими постами, модерация ответов и отдельная
инструкция «как отвечать» — она обычно отличается от инструкции для постов.

### Лимиты

Дневные лимиты постов и ответов, минимальная пауза между ответами.

## Расписание и рубрики

**Расписание** — два режима: список конкретных времён (`09:00, 14:30, 20:00`) или
интервал внутри окна (каждые 180 минут с 09:00 до 22:00). Плюс дни недели и разброс
±минут. Расписаний может быть несколько, они складываются.

Разброс детерминированный: он не пересчитывается заново при каждом проходе планировщика,
поэтому дублей в очереди не появляется.

**Рубрики** — тематические блоки со своими подсказками. Пример:

| Рубрика | Подсказка | Вес |
|---|---|---|
| Кейс из практики | Расскажи один случай: что было, что сделал, чем закончилось | 3 |
| Разбор ошибки | Опиши типичную ошибку фрилансера и как её избежать | 2 |
| Короткая мысль | Одно наблюдение в 2-3 предложения | 1 |

Чем больше вес и чем дольше рубрика не выпадала, тем выше шанс. Без рубрик тоже
работает — модель берёт тему сама.

## Поиск и ответы чужим

Вкладка «Поиск» → **+** → настройте запрос:

- **Что искать** — одно-два слова, как в поиске Threads.
- **Свежие / Популярные** — `RECENT` или `TOP`.
- **Проверять раз в N минут** — минимум 15, разумно 60.
- **Что считать подходящим** — уточнение для модели при оценке. Именно этот текст
  отличает «человек реально спрашивает совета» от «человек просто упомянул слово».
- **Как отвечать на такие посты** — инструкция для генерации комментария.
- **Стоп-слова**, **минимальная длина поста**, **пропускать комментарии** — грубые
  фильтры, которые срабатывают до обращения к модели и ничего не стоят.
- **Порог 1–10** — ниже него пост уходит в «Пропущено».
- **Готовить ответы автоматически** — выключено по умолчанию: приложение просто
  собирает находки, а ответы вы запускаете сами.
- **Максимум ответов за прогон**.

Как это выглядит в работе: раз в час приложение ищет посты, отбрасывает мусор фильтрами,
отдаёт десяток оставшихся модели одним запросом на оценку, для прошедших порог пишет
комментарий и кладёт его в «Находки» ждать вашего решения.

## Ответы на свои комментарии

Настройка аккаунта → вкладка «Ответы» → «Отвечать на комментарии».

Приложение читает последние ваши посты, забирает комментарии под ними и готовит ответ на
каждый новый. Свои же комментарии игнорируются, повторно один и тот же комментарий не
обрабатывается. Если модель считает, что перед ней оскорбление, спам или провокация —
она возвращает пустой ответ, и комментарий уходит в «Пропущено».

## Находки: что с ними делать

Раздел «Находки» (кнопка на вкладке «Поиск» или с обзора). Фильтры:

- **Ждут решения** — черновики ответов, готовые к отправке.
- **Найденные** — прошли порог, но черновика ещё нет.
- **В очереди** — ответ подтверждён и ждёт публикации.
- **Отвечено** / **Пропущено**.

Для каждой находки видно текст оригинала, балл релевантности с объяснением и черновик
ответа, который можно отредактировать прямо здесь. Кнопки: «Отправить», «Черновик»
(сгенерировать или переписать), «Пропустить», «Открыть в Threads».

## Лимиты и здравый смысл

**Что ограничивает Threads:**

| Лимит | Значение |
|---|---|
| Публикаций на профиль | 250 в сутки |
| Поисковых запросов | 2200 в сутки |
| Длина поста | 500 символов |
| Срок жизни токена | 60 дней, продлевается |

**Что ограничивает приложение (и это важнее):** дневные лимиты постов и ответов, пауза
между ответами, минимум 20 секунд между любыми публикациями, один автор не чаще раза в
неделю, случайная задержка перед отправкой ответа.

Скажу прямо, раз уж вы это строите: автоматические ответы под чужими постами — рабочий
способ находить аудиторию, и одновременно то, по чему площадки узнают ботов. Разница
между «полезный человек в комментариях» и «спам-бот» — не в технологии, а в частоте и
в том, что именно написано. Поэтому по умолчанию модерация включена, автоответ выключен,
а лимиты скромные. Первую неделю читайте каждый черновик: вы быстро увидите, что именно
надо поправить в инструкции. Отвечает модель — отвечает за это ваш аккаунт.

## Безопасность ключей

- Токены Threads, ключ DeepSeek и App Secret шифруются AES-256/GCM ключом из
  **Android Keystore** — ключ шифрования не покидает устройство и не извлекается.
- В базе данных лежат только ссылки на секреты, не сами секреты.
- Файл с секретами исключён из облачного бэкапа Android и из переноса на новое устройство.
- Секреты не отправляются никуда, кроме `graph.threads.net`, `threads.net` и `api.deepseek.com`.

При смене телефона перенесите конфигурацию через экспорт с включёнными ключами.

## Ограничения, о которых надо знать

**Всё идёт через официальный Threads API.** Никакой автоматизации через веб-интерфейс,
никаких неофициальных обходов — только то, что Meta разрешает приложениям. Отсюда же
следует, что при отзыве прав или блокировке приложения Meta работать перестанет всё.

**Приложение Meta придётся создать.** Обойти это нельзя: Threads не выдаёт токены иначе.

**Поиск нужно включать отдельно.** Право `threads_keyword_search` выдаётся не всем
приложениям автоматически — если поиск возвращает ошибку прав, проверьте разрешения.

**Ответы на комментарии видят не всё.** Приложение опрашивает последние ваши посты, а не
получает мгновенные уведомления: комментарий под очень старым постом может быть не
замечен.

**Картинки не генерируются** — DeepSeek не умеет в изображения. Вставьте прямую ссылку
на готовую картинку.

**Стоимость DeepSeek приложение не считает.** Ориентир: пост — 2–3 тысячи токенов,
оценка десятка находок — около тысячи, один комментарий — несколько сотен.

## Сборка из исходников

Нужны JDK 17+ и Android SDK (compileSdk 35, build-tools 35.0.0).

```bash
cd threadsposter

./gradlew :app:assembleDebug      # отладочная сборка
./gradlew :app:assembleRelease    # release, минифицированный
./gradlew :app:testDebugUnitTest  # тесты
```

APK появится в `app/build/outputs/apk/<тип>/`.

Если Gradle не видит SDK — создайте `local.properties` со строкой `sdk.dir=/путь/к/android-sdk`.

### Свой ключ подписи

```bash
keytool -genkeypair -v -keystore my-release.jks -alias myapp \
  -keyalg RSA -keysize 2048 -validity 10000
cp keystore.properties.example keystore.properties   # впишите путь и пароли
```

`keystore.properties` и `*.jks` в `.gitignore`. Если файл есть, release подписывается им;
иначе используется ключ разработки из репозитория.

## Что делать, если

| Симптом | Причина и решение |
|---|---|
| «Не задан API-ключ DeepSeek» | Настройки → DeepSeek → «Добавить ключ». |
| «Invalid OAuth access token» | Токен истёк или отозван. Аккаунты → «Продлить», если не помогло — вставьте новый. |
| Поиск возвращает ошибку прав | В приложении Meta не выдано `threads_keyword_search`. |
| «У аккаунта не определён threads-user-id» | Нажмите «Проверить» на карточке аккаунта. |
| Посты не создаются | Проверьте: включён Автопилот, включён аккаунт, есть включённое расписание с выбранными днями. |
| Находок нет | Слишком высокий порог, слишком узкий запрос или жёсткие стоп-слова. Начните с порога 6. |
| Ответы не уходят | Включена модерация — подтвердите в «Находках». Либо исчерпан дневной лимит. |
| Посты выходят с опозданием | Отключите оптимизацию батареи. |
| Пост обрезался | Выключен режим цепочки: вкладка «Контент» → «Длинный текст — цепочкой». |
| Всё сломалось | Журнал событий (Обзор → «Журнал событий») → «Экспорт» — там точная причина. |
