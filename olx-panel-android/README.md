# OLX Panel — приложение для Android

Панель целиком внутри телефона. Компьютер, сервер и Wi-Fi-адрес не нужны:
интерфейс, расчёт наценки, оформление объявлений и запросы к OLX работают
на самом устройстве.

## Установка

1. Скопируйте `app-debug.apk` на телефон.
2. Откройте файл, разрешите установку из этого источника.
3. Запустите «OLX Panel» — панель откроется сразу, ничего настраивать не нужно.

## Первый запуск

Считать наценку и готовить тексты можно сразу. Чтобы объявления уходили на OLX,
нужен доступ к Partner API — он бесплатный, но выдаётся **не мгновенно**.

**Шаг 1. Заявка на доступ.** Откройте в браузере **developer.olx.pl**, войдите
своим аккаунтом OLX, нажмите «Connect App» и заполните форму. Заявку проверяют
вручную: пока идёт проверка, приложение висит в статусе «Waiting for acceptance».
После одобрения `client_id` и `client_secret` придут на почту.

В форме нужно указать redirect uri — адрес, куда OLX вернёт вас после
подтверждения доступа. Подойдёт любой, например `https://localhost/oauth`:
страница по нему не открывается, приложение перехватывает переход само.
Важно только, чтобы в панели был вписан **ровно тот же** адрес.

**Шаг 2. Ключи.** Настройки → Аккаунт OLX → вставить `client_id`, `client_secret`
и тот самый redirect uri → **Сохранить ключи**.

**Шаг 3. Подключение аккаунта.** Нажать **Подключить через OAuth** и подтвердить
доступ на странице OLX. Это обязательный шаг: по правилам API объявления можно
добавлять только от имени подтверждённого аккаунта, одних ключей мало.
Пароль вводится на сайте OLX, приложение его не видит.

Панель показывает, на каком шаге вы находитесь, прямо в карточке «Аккаунт OLX».
Пока аккаунт не подключён, она работает в тестовом режиме: считает цены,
собирает текст и показывает готовое объявление, но ничего не отправляет.

## Что где хранится

Все объявления, настройки и токены лежат в памяти приложения, на самом телефоне.
Наружу ничего не уходит, кроме запросов к OLX и к страницам товаров, которые вы
импортируете.

Обратная сторона: при удалении приложения данные исчезают вместе с ним.
**Настройки → Резервная копия → Сохранить копию** отдаёт один JSON-файл, который
можно отправить себе в мессенджер или положить в облако, а потом восстановить
той же вкладкой.

## Как пользоваться

| Вкладка | Что делает |
|---|---|
| Импорт | Ссылки на товары или CSV/JSON-прайс поставщика. Файл можно выбрать прямо в телефоне |
| Наценка | Процент, фикс. надбавка, мин./макс. маржа, доставка, комиссия, округление |
| Шаблон | Единый вид всех объявлений, предпросмотр перед публикацией |
| Объявления | Список с ценой и маржой, выделение, массовая публикация |
| Настройки | Ключи OLX, контакт и город, пауза публикации, резервная копия |
| Логи | Что произошло с каждым объявлением |

Очередь публикации идёт по одному объявлению с паузой (по умолчанию 45 секунд) и
работает, **пока приложение открыто** — на это время экран не гаснет. Если свернуть
приложение надолго, Android может выгрузить его и очередь прервётся; уже
опубликованные объявления при этом не потеряются, остальные останутся в очереди.

## Чего приложение не делает

- **Не загружает фото из галереи.** OLX принимает изображения по ссылке, поэтому
  фотографии должны быть доступны в интернете — так работает импорт из фидов и
  со страниц товаров. Снимкам, которые лежат только в телефоне, нужен хостинг.
- **Не публикует в фоне.** Очередь живёт вместе с открытым приложением.
- **Не обходит правила OLX.** Публикация идёт через официальный Partner API от
  вашего аккаунта и подчиняется его лимитам.

## Сборка из исходников

Нужны JDK 17 и Android SDK (compileSdk 34, build-tools 34.0.0).

```bash
cd olx-panel-android
echo "sdk.dir=/путь/к/android-sdk" > local.properties
./gradlew testDebugUnitTest   # проверяет, что панель отдаётся из assets
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
```

Тест `PanelAssetsTest` открывает `index.html` так же, как это делает WebView,
и проходит по всем ссылкам страницы и по графу импортов — если файл лежит не по
тому адресу, по которому его просит страница, сборка падает здесь, а не белым
экраном на телефоне.

Файлы панели не дублируются: задача `syncPanelAssets` кладёт в assets те же
`olx-panel/public` и `olx-panel/shared`, что использует серверная версия.
APK собирается и в GitHub Actions при каждом пуше — готовый файл лежит в
артефактах сборки «Build APK».

### Свой ключ подписи

Debug-сборка подписана стандартным отладочным ключом: для личного использования
этого достаточно, но при смене компьютера ключ будет другим и обновление «поверх»
не встанет. Для постоянного ключа:

```bash
keytool -genkey -v -keystore olx-panel.jks -keyalg RSA -keysize 2048 -validity 10000 -alias olx
./gradlew assembleRelease \
  -POLX_KEYSTORE_FILE=/абсолютный/путь/olx-panel.jks \
  -POLX_KEYSTORE_PASSWORD=… -POLX_KEY_ALIAS=olx -POLX_KEY_PASSWORD=…
```

Keystore в репозиторий не кладите — он в `.gitignore`.

## Как это устроено

```
app/src/main/java/pl/olxpanel/app/
  MainActivity.java    WebView с панелью из assets, окно OAuth, меню, выбор файлов
  NativeBridge.java    HTTP без CORS, хранение данных, файл резервной копии
assets/panel/          интерфейс панели (копия olx-panel/public)
assets/panel/shared/   логика цен, оформления, разбора (копия olx-panel/shared)
```

Панель определяет, что работает в приложении, по наличию моста `OlxNative`,
и переключается на локальный движок `js/local-api.js` — тот же набор запросов,
что у сервера, но выполняемый на устройстве.
