# OLX Panel — Android

Приложение-оболочка: панель открывается на телефоне как обычное приложение,
без адресной строки и вкладок браузера. Сама панель продолжает работать на компьютере,
телефон только показывает её интерфейс.

## Установка готового APK

1. Скопируйте `app-debug.apk` на телефон (кабель, Telegram себе, облако — как удобно).
2. Откройте файл на телефоне. Android спросит разрешение на установку из этого источника — разрешите.
3. Запустите «OLX Panel», введите адрес компьютера с панелью, например `http://192.168.1.10:8787`,
   и токен из `PANEL_TOKEN`, если вы его задавали.

Адрес компьютера в локальной сети: на Linux/macOS — `hostname -I` или `ipconfig getifaddr en0`,
на Windows — `ipconfig`, строка IPv4. Телефон и компьютер должны быть в одной сети Wi-Fi.

Панель должна слушать не только localhost — запустите её так:

```bash
HOST=0.0.0.0 npm start
```

И обязательно задайте `PANEL_TOKEN` в `.env`: без него панель в локальной сети открыта
всем устройствам этой сети.

## Что умеет приложение

- запоминает адрес и токен, при следующем запуске открывает панель сразу;
- проверяет связь с сервером до сохранения адреса и объясняет, что не так;
- потянуть вниз — обновить страницу;
- кнопка «⋯» внизу справа — обновить, сменить сервер, очистить кэш;
- «Назад» ходит по истории панели, выход — двойным нажатием;
- выбор файла работает: CSV-прайс можно загрузить прямо с телефона;
- ссылки на OLX открываются в системном браузере, а не внутри приложения.

## Сборка из исходников

Нужны JDK 17 и Android SDK (compileSdk 34, build-tools 34.0.0).

```bash
cd olx-panel-android
echo "sdk.dir=/путь/к/android-sdk" > local.properties
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

APK собирается и в GitHub Actions при каждом пуше — готовый файл лежит в артефактах
сборки «Build APK».

### Подписанный release-сборкой

Debug-версия подписана стандартным отладочным ключом: для личного использования этого
достаточно, но при смене компьютера ключ будет другой и обновление «поверх» не встанет.
Для своего постоянного ключа:

```bash
keytool -genkey -v -keystore olx-panel.jks -keyalg RSA -keysize 2048 -validity 10000 -alias olx
./gradlew assembleRelease \
  -POLX_KEYSTORE_FILE=/абсолютный/путь/olx-panel.jks \
  -POLX_KEYSTORE_PASSWORD=… -POLX_KEY_ALIAS=olx -POLX_KEY_PASSWORD=…
```

Keystore в репозиторий не кладите — он в `.gitignore`.

## Без APK: установка как PWA

Если ставить приложение не хочется, откройте панель в Chrome на телефоне и выберите
«Установить приложение» / «Добавить на главный экран». Панель установится ярлыком,
запустится без адресной строки и будет работать так же — это тот же интерфейс,
адаптированный под телефон.

## Структура

```
app/src/main/
  java/pl/olxpanel/app/
    SetupActivity.java   экран адреса и токена, проверка связи
    MainActivity.java    WebView, pull-to-refresh, меню, выбор файлов
    Prefs.java           хранение адреса, нормализация URL
  res/layout/            вёрстка двух экранов
  res/xml/               политика сетевой безопасности (http в локальной сети)
```
