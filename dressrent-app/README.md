# DressRent Studio — Android-приложение для аренды платьев

Оффлайн-приложение для студии проката вечерних образов: гардероб, брони, платежи,
клиентская база и **план дня в деньгах** с готовым списком действий на каждое утро.

## Сначала — честно про «50 $ в день автоматически»

Программы, которая сама зарабатывает 50 $ в день с нуля, не существует. Всё, что так
себя продаёт, — это либо накрутка и нарушение правил площадок, либо схема, где платит
сам пользователь. Приложение не может создать спрос из воздуха.

Что реально можно сделать — **перестать терять деньги, которые уже рядом**. В прокате
платьев выручку съедают три вещи: заявка, на которую не ответили вовремя; доплата, про
которую забыли; платье, которое зависло у клиентки лишний день. Это приложение закрывает
именно их.

Считаем по вашим же ценам с сайта DressRentDubai:

| | AED | ≈ USD |
|---|---|---|
| План дня по умолчанию | 184 | 50 $ |
| Коктейльное платье | от 350 | ≈ 95 $ |
| Вечернее платье | от 650 | ≈ 177 $ |
| Премиум | от 1 200 | ≈ 327 $ |

**Одна коктейльная аренда закрывает план почти на два дня вперёд.** То есть цель «50 $ в
день» — это примерно 15–16 аренд в месяц. Не магия, а дисциплина: вовремя ответить,
вовремя забрать деньги, вовремя вернуть платье в оборот. Приложение следит за этим за вас.

## Что внутри

**Экран «Сегодня»** — план дня в деньгах:
- сколько получено сегодня из плана (в AED и в долларах), прогресс-бар, выручка за 7 дней;
- **план действий**: конкретные задачи, отсортированные по срочности, с уже написанным
  текстом сообщения и кнопкой «Написать» → WhatsApp открывается с готовым текстом;
- потенциал дня: сколько денег принесут эти задачи, если их закрыть.

Задачи появляются сами, из данных:

| Задача | Когда появляется | Зачем |
|---|---|---|
| Просрочен возврат | платье не вернули в срок | платье не работает и не сдаётся |
| Забрать доплату | сегодня выдача, оплачено не полностью | деньги в кассу сегодня |
| Возврат сегодня | срок возврата наступил | освободить образ под следующую бронь |
| Дожать заявку | заявка без оплаты старше N дней | самая дешёвая конверсия |
| Попросить отзыв | аренда завершена, отзыв не просили | отзывы приводят новые заявки |
| Вернуть клиентку | не арендовала N дней | постоянные соглашаются чаще всех |
| Продать свободный день | ни выдач, ни заявок | пустой день не закроется сам |

**Утренняя сводка** — раз в день в выбранное время push с планом: сколько до цели,
сколько выдач и возвратов, три самых срочных задачи и их суммарная стоимость.

**Гардероб** — образы с ценой за день, залогом, закупочной ценой и фото. По каждому видно,
сколько раз сдан, сколько заработал и на сколько процентов окупился.

**Брони** — статусы `Заявка → Подтверждено → Выдано → Возвращено`, защита от
двойного бронирования одного платья на пересекающиеся даты, цена считается
автоматически по прайсу и числу дней.

**Платежи** — предоплата, доплата, доп. услуги, залог и возврат залога. В план дня
попадает только выручка: **залог — это деньги клиентки, а не ваш доход**. Выручка
засчитывается в тот день, когда деньги реально получены.

**Клиенты** — кто сколько принёс, откуда пришёл, кнопка WhatsApp в один тап.

## Приватность и стоимость

Данные лежат только на телефоне (SQLite + DataStore). Нет сервера, аккаунтов, подписки
и аналитики: ни один платёж и ни один контакт никуда не уходит. Интернет приложению не
нужен вообще — WhatsApp открывается уже установленным на телефоне приложением.

## Установка

Готовый APK: [`dist/DressRentStudio-1.0.apk`](dist/DressRentStudio-1.0.apk)

1. Скачайте файл на Android-телефон (Android 8.0 и новее).
2. Откройте его и разрешите установку из этого источника.
3. При первом запуске разрешите уведомления — иначе утренняя сводка не придёт.
4. Настройки → «Загрузить демо-данные», чтобы посмотреть, как всё работает,
   потом «Очистить все данные» и заводите свой гардероб.

APK подписан отладочным ключом — этого достаточно, чтобы установить его себе.
Для публикации в Google Play нужен собственный keystore (см. `app/build.gradle.kts`).

## Сборка из исходников

```bash
cd dressrent-app
./gradlew testDebugUnitTest     # 17 юнит-тестов
./gradlew assembleRelease       # app/build/outputs/apk/release/app-release.apk
```

Нужен JDK 17+ и Android SDK 35. CI собирает APK на каждый push:
`.github/workflows/android.yml`.

## Стек

Kotlin · Jetpack Compose (Material 3) · Room · WorkManager · DataStore · Coil ·
minSdk 26 · targetSdk 35 · релизный APK ≈ 2 МБ.
