# Livada — магазин техники Apple в Румынии

**Livada** («сад» по‑румынски; слоган *Tehnologia Apple, culeasă cu grijă* — «техника Apple, собранная с заботой») — интернет‑магазин новой техники Apple для Румынии: каталог, корзина, оформление заказа со всеми румынскими службами доставки и пачкоматами на карте, личный кабинет с подтверждением email и панель администратора на румынском и русском. Магазин целиком на **двух языках — румынском и английском** (`/en/…`), включая каталог, письма и сообщения об ошибках.

- **149 товаров, 1237 вариантов** — актуальная линейка Apple на октябрь 2026: iPhone (вкл. iPhone Duo, 18 Pro/Pro Max, Air, 17, 17e, 16), Mac, iPad (iPad Pro и со стеклом с нанотекстурой), Apple Watch, AirPods и все модели Beats во всех цветах, Apple TV/HomePod, AirTag и **весь каталог аксессуаров Apple и Beats — 106 товаров, 825 вариантов**: все цвета, размеры ремешков и корпусов, модели iPhone для чехлов, длины кабелей, разъёмы и раскладки клавиатур (132 цвета с румынскими названиями). Настоящие артикулы Apple (MPN), средние рыночные цены в леях с НДС 21%.
- **Фото в едином стиле**: прозрачный фон, одинаковые поля, WebP 480/1000 px + JPEG‑миниатюры для писем.
- **11 506 пачкоматов и пунктов выдачи** во всех 42 уездах: FANbox (3249), GLS (1879 локеров + 1036 ParcelShop), DPD (754 DPD Box + 1708 DPD Pickup), Cargus (168 локеров + 1908 Ship & Go) — официальные списки самих перевозчиков; easybox (804) — из OpenStreetMap, полный список подтягивается из API Sameday с аккаунтом магазина. Оригинальные логотипы перевозчиков везде: в checkout, на пинах карты, на странице доставки, в письмах и админке.
- **Карта выбора пачкомата**: поиск по любому населённому пункту Румынии (13 851, включая сёла без пачкоматов — тогда показываются ближайшие), улице, индексу или названию; пины с логотипом сети, кластеры-«пончики» с долями сетей, фильтры по сетям и «только локеры 24/7», список по расстоянию, карточка точки (ориентир «справа от входа», часы, цена, срок, наложенный платёж, маршрут), «рядом со мной», режимы «Карта/Список» на телефоне. Та же карта открыта для всех на странице «Livrare».
- **Две языковые версии**: румынская (основная, `/`) и английская (`/en/…`) — все страницы, названия и описания товаров, цвета, характеристики, checkout, кабинет, письма (на языке клиента), сообщения сервера и скрипты в браузере. Переключатель языка в шапке, меню и подвале; `hreflang`, двуязычный sitemap.
- **Без зависимостей**: только Node.js ≥ 22.5 (встроенные `node:sqlite`, `node:http`, `node:crypto`). `npm install` не нужен.

## Быстрый старт

```bash
cd livada
npm run dev          # http://localhost:8080 — при первом запуске база заполняется каталогом и демо‑заказами
```

| Что | Где |
|---|---|
| Магазин | http://localhost:8080 |
| Админ‑панель | http://localhost:8080/admin — `admin@livada.ro` / `Livada2026!` (только в development) |
| Входящие письма (без SMTP) | http://localhost:8080/dev/mail — здесь видны письма с кодом подтверждения, заказы и т. д. |
| Тестовая карта | на странице оплаты — симуляция 3‑D Secure, «успех» или «отказ» |

Промокоды: `BUNVENIT50` (−50 лей на первый заказ от 500 лей), `LIVADA10` (−10%, максимум 300 лей), `TRANSPORT0` (бесплатная доставка), `VARA2026` (истёк — для проверки ошибки).

Другие команды:

```bash
npm start                    # production-режим (нужны APP_SECRET и ADMIN_PASSWORD)
npm run seed                 # заполнить пустую базу каталогом/пачкоматами (без демо-заказов)
npm run seed:demo            # то же + 48 демо-клиентов и 160 демо-заказов для графиков
npm run create-admin -- ana@livada.ro --role manager --name "Ana Ionescu"
npm test                     # 24 теста: модули + HTTP-сценарии (регистрация, заказ, оплата, админка, безопасность)
npm run e2e                  # 15 шагов в настоящем браузере (Playwright), скриншоты в test-results/e2e/
npm run screens              # скриншоты всех страниц: RO/EN × светлая/тёмная тема × компьютер/телефон + галерея (см. ниже)
node tools/i18n-scan.mjs http://localhost:8080 --all   # ищет непереведённые румынские строки на английских страницах
python3 -m unittest discover -s tools/tests            # тесты сборщика пачкоматов (коннекторы Sameday/Packeta на мок-сервере)
```

## Что умеет

**Магазин.** Главная, категории с фильтрами и сортировкой, «Новинки», «Акции», живой поиск (⌘K, без диакритики), карточка товара с конфигуратором (цвет/память/корпус/подключение, разница в цене, остатки, дата доставки), избранное, корзина‑шторка, промокоды, статичные страницы (доставка, возврат 30 дней, гарантия, условия, конфиденциальность, cookies, помощь, контакты), sitemap, Open Graph, JSON‑LD, тёмная тема, адаптив.

**Регистрация.** Письмо с 6‑значным кодом и кнопкой‑ссылкой (код живёт 30 минут, 5 попыток, повторная отправка через 60 с; ссылка работает на другом устройстве). После подтверждения — приветственное письмо с подарочным кодом. Восстановление пароля, смена пароля с завершением других сессий, экспорт своих данных (GDPR).

**Доставка** (всё настраивается в админке — цены, сроки, порог бесплатной доставки, наложенный платёж):
- курьер до двери: FAN Courier, Sameday, Cargus, DPD, GLS, Poșta Română;
- доставка в тот же день по Бухаресту и Ильфову (до 14:00);
- пачкоматы и пункты выдачи: easybox, FANbox, Cargus Ship & Go, DPD Box / DPD Pickup, GLS ParcelLocker / ParcelShop — выбор на карте (Packeta Z‑BOX включается, когда есть API‑ключ: без списка точек сеть в checkout не показывается);
- самовывоз из шоурума.

Бесплатно от 500 лей (курьер) и от 300 лей (пачкоматы). Сроки считаются в рабочих днях по времени Бухареста (воскресенье пропускается, отсечка в 16:00).

**Оплата.** Карта онлайн (страница‑симуляция 3‑D Secure), наложенный платёж (+9,99 лей, до 15 000 лей), банковский перевод с реквизитами в письме, рассрочка 0% на 3/6/12 месяцев от 500 лей. Физлица и юрлица (CUI проверяется по контрольной цифре).

**Админ‑панель** (RO/RU, переключатель внизу меню): дашборд с графиками продаж и KPI, заказы (фильтры, CSV, смена статуса с письмом клиенту, AWB со ссылкой на отслеживание, отметка оплаты, внутренние заметки, печать проформы), товары (редактирование, варианты и остатки, массовое изменение цен в %, загрузка фото), клиенты (блокировка, ручное подтверждение email), промокоды, способы доставки и импорт пачкоматов (JSON), предпросмотр всех писем и тестовая отправка, сообщения из формы контактов, настройки компании и шоурума, журнал действий. Роли: `admin` и `manager` (менеджер работает с заказами, товарами и клиентами, но не меняет настройки и доставку, не блокирует клиентов, не удаляет промокоды и не видит журнал).

## Языки

Исходные строки в коде — румынские; они же ключи перевода. Английские словари лежат в `src/i18n/en/*.json` (интерфейс, checkout, страницы, письма, строки для браузера), переводы каталога — в `data/i18n/catalog-*.en.json` (названия, описания, характеристики, цвета, группы опций). Язык запроса определяется по префиксу `/en`, для API — по заголовку `X-Lang`/cookie `lv_lang`; ссылки, редиректы и JSON автоматически получают нужный префикс. Язык клиента запоминается в аккаунте и в заказе — письма о статусе заказа уходят на нём же.

Чтобы найти непереведённое: `/dev/i18n` (в development) показывает строки, которые запрашивались без перевода, а `node tools/i18n-scan.mjs <url> --all` обходит английские страницы и ищет румынский текст. Словари перечитываются на лету в development.

## Скриншоты и галерея

`npm run screens` поднимает магазин на копии базы и снимает каждую страницу и состояние (вкладки, модальные окна, шторки, карта пачкоматов, шаги checkout, кабинет, админка, письма) в 8 вариантах: язык (RO/EN; админка — RO/RU) × тема (светлая/тёмная) × устройство (1440 px / iPhone 390 px). Результат — папка `screenshots/` с WebP‑снимками во всю высоту страницы, миниатюрами, фото всех товаров и `index.html` — галереей с фильтрами, поиском, сравнением вариантов рядом и просмотром с клавиатуры; она открывается прямо с диска. Папка в `.gitignore`. Для публикации онлайн `python3 tools/screenshots/pack_web.py screenshots <папка>` собирает облегчённую версию (≈240 МБ, ≈290 файлов: миниатюры в спрайтах, полные снимки в пакетах, которые галерея раскрывает в браузере).

## Настройка для продакшена

Скопируйте `.env.example` в `.env` и заполните:

| Переменная | Зачем |
|---|---|
| `NODE_ENV=production` | включает HSTS, строгие cookie и отключает `/dev/mail` |
| `APP_SECRET` | `openssl rand -hex 32` — подпись CSRF‑токенов и cookie |
| `PUBLIC_URL` | `https://livada.ro` — используется в письмах, sitemap и Open Graph |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | первый администратор (создаётся, если в базе нет ни одного) |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM` | любой SMTP: Amazon SES, Brevo, Mailgun, Postmark, Google Workspace. Для доставляемости настройте SPF, DKIM и DMARC для домена отправителя |
| `SHOP_NOTIFY_EMAIL` | куда приходят уведомления о новых заказах |
| `DATA_DIR` | папка с базой SQLite, загруженными фото и исходящими письмами — **её нужно бэкапить** |
| `PAYMENT_MOCK` | `1` — включить тестовую страницу оплаты картой и в production (только для демо!) |
| `TRUST_PROXY` | `true`, если перед приложением стоит nginx/Caddy (для правильного IP в лимитах) |
| `MAP_TILES_URL`, `MAP_TILES_TONE` | подложка карты; по умолчанию OpenStreetMap в сером тоне, для большого трафика нужен провайдер с ключом (MapTiler, Stadia — примеры в `.env.example`) |

Запуск за обратным прокси с HTTPS (Caddy: `livada.ro { reverse_proxy 127.0.0.1:8080 }`), процесс — через systemd или pm2. База — один файл `DATA_DIR/livada.db` (WAL), бэкап: `sqlite3 livada.db ".backup backup.db"`.

## Что заменить на реальное

Все данные компании — правдоподобные заглушки, а не данные реальной фирмы. **CUI `RO48731906` специально невалиден** (не проходит контрольную цифру), IBAN содержит `AAAA`.

1. **Админка → Настройки**: юрлицо, CUI, Reg. Com., EUID, адрес, телефон, IBAN, банк, соцсети, шоурум (адрес, часы, координаты). Эти данные попадают в подвал, письма, проформу и страницы условий.
2. **Тексты условий** (`src/views/store/pages.js`): условия продажи, политика конфиденциальности и cookies написаны как разумный шаблон по законодательству RO/ЕС — их должен проверить юрист.
3. **Цены и остатки** — в админке (в т. ч. массовое изменение в %). Остатки в каталоге — демонстрационные.
4. **Платёжный шлюз**: страница `/plata/:token` — симуляция, она работает только в development (или с `PAYMENT_MOCK=1`). В production без шлюза оплата картой и рассрочка скрыты — остаются наложенный платёж и перевод. Подключите Netopia, EuPlătesc или Stripe: обработчик успешной оплаты должен вызвать `completeCardPayment(order)` из `src/services/orders.js` (после проверки подписи webhook).
5. **Курьеры**: AWB сейчас вводится вручную в заказе. Для автоматической генерации AWB подключаются API FAN Courier / Sameday / Cargus / DPD / GLS.
6. **Пачкоматы**: `python3 tools/build_lockers.py` скачивает официальные списки (FAN Courier, GLS, Cargus, DPD — те же файлы, что грузят их собственные карты), нормализует их (диакритика по справочнику населённых пунктов INS, уезд по индексу, сектор Бухареста, часы работы, ориентиры, дубликаты) и пишет `data/lockers.json`, `data/places.json` и отчёт о качестве `tools/data/lockers-report.json`. Точки, у которых координаты не в том уезде, что адрес (30 шт.), отбрасываются и попадают в отчёт. **easybox**: Sameday не публикует список открыто (сайт закрыт проверкой Cloudflare), поэтому без аккаунта берутся 804 точки из OpenStreetMap; с аккаунтом задайте `SAMEDAY_USER`/`SAMEDAY_PASSWORD` — скрипт заберёт все ~6000 easybox из API Sameday. **Packeta**: `PACKETA_API_KEY`. Сервер сам синхронизирует базу при изменении файла (новые точки добавляются, исчезнувшие скрываются, заказы не трогаются). Разовый импорт — **Админка → Доставка → Импорт**; там же таблица источников и покрытия по уездам.
7. **e‑Factura (ANAF)** и фискальные чеки не реализованы — подключаются через сервис выставления счетов (SmartBill, Oblio и т. п.).

## Структура

```
src/
  server.js, app.js        HTTP-сервер, сессии, CSRF, маршрутизация, обработка ошибок
  config.js                настройки из .env
  db/                      schema.sql, миграции, seed (каталог, пачкоматы, демо-данные)
  lib/                     html-шаблоны с экранированием, http, security, mailer (свой SMTP-клиент), static
  services/                catalog, cart, orders, users, shipping, stats, mail-templates (все письма)
  routes/                  store, account, api, admin, dev
  views/                   store/* (страницы магазина), admin/* (панель, i18n RO/RU, графики)
  cli/create-admin.js
public/                    css, js (ES-модули, прогрессивное улучшение), img (товары, бренд), fonts, vendor/leaflet
data/                      catalog.json (149 товаров), catalog-retired.json, lockers.json (11 506 пачкоматов и пунктов), places.json (13 851 населённый пункт)
tools/                     сборка каталога и фото (Python + Pillow), пачкоматов (официальные списки + OSM), логотипов перевозчиков, бренда
test/                      unit + HTTP (node:test), e2e (Playwright)
```

Пересборка каталога: `python3 tools/build_catalog.py` (нужен Pillow; `--skip-images` — только данные; уже обработанные фото пропускаются). Аксессуары собираются из Apple Store Германия: `python3 tools/scrape_accessories.py` сохраняет все семейства с вариантами, ценами и фото каждого цвета в `tools/data/apple_accessories_de.json`, а правила в `tools/accessories_data.py` превращают их в товары (румынские названия, группы, что исключить — Hermès, Vision Pro, чехлы для старых iPhone).

Обновление каталога в работающем магазине — автоматическое: при старте сервер сравнивает хэш `data/catalog.json` и добавляет новые товары и варианты, обновляет опции и фото, а товары из `data/catalog-retired.json` скрывает (не удаляет). Заказы, тексты, цены и скрытые в админке товары и варианты не трогаются.

## Безопасность

Пароли — scrypt; тестовая оплата отключена в production; сессии хранятся как SHA‑256 токена; cookie `HttpOnly` + `SameSite=Lax` (+ `Secure` в production); CSRF‑токен + проверка Origin на всех POST; CSP без inline‑скриптов (import map разрешён по хэшу); лимиты попыток на вход, коды, сброс пароля, промокоды и формы; все SQL‑запросы параметризованы; загрузка фото проверяет сигнатуру файла; заказы гостей открываются только по случайному токену.
