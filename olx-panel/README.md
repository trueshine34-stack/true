# OLX Panel — массовое выставление объявлений с наценкой

Панель для OLX.pl: импорт товаров из внешних источников, автоматическая наценка,
единое красивое оформление объявления и публикация через **официальный Partner API OLX**.

Работает двумя способами: как приложение на телефоне (компьютер не нужен вообще)
и как сервер на ПК. Логика в обоих случаях одна и та же, зависимостей нет —
только Node.js 20+ для серверной версии.

```
npm start          # сервер панели на http://127.0.0.1:8787
npm test           # 32 теста логики цен, оформления и импорта
```

---

## Прежде чем начать

Панель публикует объявления от вашего имени и по правилам OLX. Копирование чужих
объявлений (фото и текст других продавцов) нарушает регламент OLX и авторские права —
за это блокируют аккаунт. Используйте панель с источниками, на которые у вас есть права:
фиды и прайсы поставщиков, собственные фото, товары под дропшиппинг-договор.

Поэтому в панели по умолчанию включена очистка: чужие телефоны, e-mail, ссылки и
упоминания других площадок вырезаются из текста до публикации.

---

## Два режима

Логика одна, а работать панель умеет двумя способами.

| Режим | Что нужно | Когда подходит |
|---|---|---|
| **Приложение** | только телефон | компьютера нет вообще: панель, данные и запросы к OLX живут внутри Android-приложения |
| **Сервер** | компьютер с Node.js | панель крутится на ПК, телефон открывает её как сайт или PWA |

Расчёт наценки, оформление объявлений и разбор фидов лежат в `shared/` и в обоих
режимах выполняются одним и тем же кодом — приложение носит эти файлы внутри себя.

### Приложение (без компьютера)

Всё в [`olx-panel-android/`](../olx-panel-android/): установили APK, ввели ключи
Partner API прямо в приложении, работаете. Данные хранятся в памяти телефона,
резервная копия выгружается одним файлом.

Автономный режим можно посмотреть и в браузере — откройте панель с `?standalone=1`,
и она будет считать и хранить всё локально, без обращения к серверу.

### Сервер (если компьютер есть)

Панель поднимается на ПК, телефон открывает её по адресу в локальной сети:

```bash
HOST=0.0.0.0 PANEL_TOKEN=придумайте-пароль npm start
```

Токен здесь обязателен: без него панель открыта любому устройству в вашей сети.
Адрес компьютера смотрите через `hostname -I` (Linux), `ipconfig getifaddr en0`
(macOS) или `ipconfig` (Windows). В Chrome на телефоне панель ставится на главный
экран как PWA: оболочка кэшируется и открывается без адресной строки.

Вёрстка в обоих режимах одна и та же и рассчитана на маленький экран: таблица
объявлений превращается в карточки, формы идут в одну колонку, редактор
открывается на весь экран.

## Установка серверной версии

```bash
cd olx-panel
cp .env.example .env      # заполнить ключи
npm start
```

Ключи Partner API берутся в кабинете разработчика OLX: https://developer.olx.pl —
зарегистрируйте приложение, укажите redirect URI `http://127.0.0.1:8787/oauth/callback`,
скопируйте `client_id` и `client_secret` в `.env`.

Затем откройте вкладку **Настройки → Подключить через OAuth** — панель сама сохранит
`refresh_token` в `data/tokens.json` и будет обновлять доступ автоматически.

Без ключей панель работает в режиме **dry-run**: считает цены, готовит текст и payload,
показывает предпросмотр, но ничего не отправляет в OLX. Удобно, чтобы всё настроить заранее.

## Как устроена работа

**1. Импорт.** Вкладка «Импорт»:

| Способ | Что делает |
|---|---|
| По ссылкам | Забирает данные страницы: микроразметка JSON-LD → внутреннее состояние OLX → OpenGraph. До 50 ссылок за раз |
| CSV / JSON | Прайс поставщика. Колонки распознаются на русском, польском и английском (`title`/`tytuł`/`название`, `price`/`cena`/`цена` и т.д.) |
| Вручную | Кнопка «Открыть» в карточке объявления — полный редактор |

Неизвестные колонки файла становятся параметрами товара и попадают в блок характеристик.
Повторный импорт того же товара не создаёт дубль — сверка идёт по ссылке, артикулу и заголовку.

**2. Наценка.** Вкладка «Наценка» — правило считается так:

```
наценка = закупка × процент + фикс. надбавка
наценка ограничивается снизу мин. маржой и сверху макс. маржой
цена = (закупка + наценка + доставка) / (1 − комиссия%)
цена округляется выбранным способом (…,99 / до 5 / до 10 / до 50 / до 100 zł)
```

Комиссия площадки добавляется «сверху», чтобы чистая маржа не съедалась.
Правила накладываются слоями, от слабого к сильному:

```
базовое правило → правило категории → правило источника → правило объявления → ручная цена
```

Таблица справа показывает, как правило ляжет на реальные цены до сохранения.

**3. Оформление.** Вкладка «Шаблон» — единый вид всех объявлений:

- заголовок и текст собираются из переменных `{{title}}`, `{{description}}`, `{{price}}`,
  `{{brand}}`, `{{highlights}}`, `{{hashtags}}` плюс любых своих;
- заголовок чистится от `!!!`, «PROMOCJA», эмодзи и КАПСА, режется по границе слова до 70 знаков;
- текст: схлопываются пустые строки, убирается капс, добавляются характеристики и хештеги;
- предложения с чужими контактами удаляются целиком, а не превращаются в обрубки.

Предпросмотр справа показывает объявление ровно в том виде, в каком его увидит покупатель,
и предупреждает, если публикация не пройдёт (нет категории, города, фото или цены).

**4. Публикация.** Вкладка «Объявления»: выбрать → «Опубликовать выбранные».
Очередь идёт по одному объявлению с паузой `PUBLISH_INTERVAL_MS` (по умолчанию 45 с) —
это защита от лимитов API и от того, чтобы пачка выглядела спамом.
Каждое объявление проходит локальную валидацию до отправки, после публикации в карточке
появляется ссылка на OLX. Ошибки видны в строке объявления и во вкладке «Логи».

## Структура

```
shared/                 логика, общая для сервера и приложения
  pricing.js            расчёт цены и слои правил      ← покрыт тестами
  formatter.js          очистка, шаблон, заголовок      ← покрыт тестами
  importer.js           разбор URL / CSV / JSON        ← покрыт тестами
  olx-payload.js        сборка и проверка объявления OLX
  olx-client.js         OAuth2 и Partner API поверх любого транспорта
server/
  index.js              HTTP-сервер, роутинг, статика, токен панели
  routes/api.js         все эндпоинты JSON API
  lib/config.js         .env и настройки
  lib/store.js          JSON-хранилище с атомарной записью
  lib/olx.js            оправа общего клиента: fetch + файл токенов
  lib/importer.js       оправа импорта: загрузка страниц через fetch
  lib/publisher.js      подготовка, валидация, очередь публикации
public/                 панель (без сборщика)
  js/local-api.js       автономный движок: тот же API внутри устройства
data/                   объявления, настройки, токены, логи
```

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/state` | настройки, статистика, состояние очереди |
| GET/PUT | `/api/settings` | настройки панели |
| GET/POST | `/api/listings` | список / создание |
| GET/PATCH/DELETE | `/api/listings/:id` | карточка, правка, удаление |
| GET | `/api/listings/:id/preview` | готовый текст, цена, payload, валидация |
| POST | `/api/listings/bulk` | массово: очередь, правка, удаление |
| POST | `/api/import/url` · `/api/import/file` | импорт |
| POST | `/api/pricing/preview` · `/api/pricing/apply` | расчёт и применение наценки |
| POST | `/api/publish` · `/api/publish/one` · `/api/publish/stop` | публикация |
| GET | `/api/olx/me` · `/categories` · `/cities` | справочники OLX |
| GET/DELETE | `/api/logs` | журнал |

## Безопасность

Панель поднимается на `127.0.0.1`. Если выносите её в сеть — обязательно задайте
`PANEL_TOKEN` в `.env` и держите панель за HTTPS-прокси. Файлы `.env` и `data/*.json`
содержат ключи и токены доступа к вашему аккаунту OLX и в git не попадают.
