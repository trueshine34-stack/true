# Календарь здоровья

Android-приложение для отслеживания привычек, влияющих на здоровье. Первый (и пока
единственный) трекер — **дни без курения**.

## Что умеет

- **Сегодня** — живой счётчик серии без курения (дни и время до секунды), прогресс до
  следующей вехи восстановления, не выкуренные сигареты, сэкономленные деньги,
  возвращённое время жизни и лучшая серия. Оттуда же отмечается срыв за сегодня.
- **Календарь** — месячная сетка, где зелёным отмечены дни без курения, красным — срывы.
  Нажатие на день ставит или снимает отметку срыва.
- **Здоровье** — 13 вех восстановления организма от 20 минут до 15 лет с процентом
  прогресса по каждой. Сроки — усреднённые данные ВОЗ и NHS.
- **Настройки** — дата отказа, сигарет в день, сигарет в пачке, цена пачки, валюта,
  полный сброс трекера.

Данные хранятся в `SharedPreferences` на устройстве. Приложение не запрашивает
разрешений и не выходит в сеть.

## Как считается статистика

- **Серия** идёт от даты отказа, а после срыва — с полуночи следующего дня.
- **Срыв** считается целым днём курения: он не входит в дни без курения, обрывает серию
  и вычитается из сэкономленных сигарет и денег.
- **Время жизни** — 11 минут на каждую невыкуренную сигарету (усреднённая оценка).

## Готовый APK

`release/health-calendar-1.0-debug.apk` — отладочная сборка, подписанная стандартным
debug-ключом Android. Ставится на устройство напрямую:

```bash
adb install -r release/health-calendar-1.0-debug.apk
```

Без ADB: скопируйте файл на телефон и откройте его, разрешив установку из этого
источника. Для публикации в Google Play нужна релизная сборка со своим ключом
(`assembleRelease` + подпись).

## Сборка из исходников

Требуется JDK 17+ и Android SDK (platform 35, build-tools 35.0.0). Путь к SDK задаётся
переменной `ANDROID_HOME` или файлом `local.properties`.

```bash
./gradlew :app:assembleDebug        # APK в app/build/outputs/apk/debug/
./gradlew :app:testDebugUnitTest    # юнит-тесты расчётов
```

## Структура

```
app/src/main/java/com/trueshine/healthcalendar/
├── data/          состояние трекера и его хранение
├── domain/        расчёт статистики и вехи восстановления
└── ui/            Compose-экраны, тема, форматирование
```

Каждый следующий трекер календаря (сон, вода, шаги) добавляется как своя пара
`data`/`domain` и вкладка в `HealthCalendarApp.kt`.

## Стек

Kotlin 2.0, Jetpack Compose (Material 3), minSdk 26, targetSdk 35.
