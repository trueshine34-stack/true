What it does

MatrAIx instantiates sampled persona records as LLM agents and runs them through reproducible tasks across four environments. Shared telemetry and task-owned verification connect individual trajectories to subgroup- and population-level findings.

Survey

Structured questionnaires answered in-character by persona-conditioned agents.

AI Chatbot

Multi-turn conversations against a chat API, scored by task-owned verifiers.

Web

Browser-driven flows via Playwright and computer-use agents on real pages.

App

Native desktop and mobile targets, including macOS, iOS, and Linux apps.

Architecture

Persona synthesis feeds the runtime; the runtime drives agents through task environments and returns verified trajectories.

Run it locally

Requires Docker, Python 3.12 with uv, and Node.js 20+ for the frontends.

# clone this repository and enter the vendored project
git clone https://github.com/trueshine34-stack/true.git
cd true/matraix-persona-8b

# install
uv venv --python 3.12
uv pip install -e .
uv pip install -e packages/playground

# smoke test — no API key needed, but Docker must be running
uv run harbor run -c configs/jobs/example-job-recipe/harbor-smoke-local.yaml

What is and isn't hosted here

This page is static hosting.

GitHub Pages serves files, not servers. The Handbook on this domain is the live, complete documentation — rebuilt automatically from matraix-persona-8b/docs/ on every push to main.

The MatrAIx runtime itself cannot run here: harbor jobs need Docker containers, the Playground and viewer need a Python/FastAPI backend, and persona agents need model API keys. Those run on your own machine or infrastructure — follow the Quickstart above.
