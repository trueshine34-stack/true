Фото и данные каталога сохраняются прямо в репозиторий GitHub через GitHub API, поэтому их видят все посетители сайта, а не только этот браузер. Для этого нужен Personal Access Token с правом Contents: Read and write только на этот репозиторий (создать: GitHub → Settings → Developer settings → Fine-grained tokens). Токен хранится только в этом браузере (localStorage) и никогда не попадает в код сайта — не используйте его на чужих/публичных компьютерах.
