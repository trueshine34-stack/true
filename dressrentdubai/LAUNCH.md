# 🚀 План запуска DressRentDubai

Пошаговый чек-лист подготовки сайта к идеальному запуску. Пункты идут в порядке приоритета — верхние блокируют запуск, нижние можно делать после.

---

## 1. Контент (обязательно до запуска)

- [ ] **Фотосъёмка каталога.** Сейчас в галерее стоковые фото Unsplash — заглушки. Нужна профессиональная съёмка платьев: портретный формат 3:4, единый фон/свет, минимум 4–6 образов в каждой категории. Файлы подключаются в одном месте — массив `looks` в `js/script.js` (поле `img`).
- [ ] **Реальный телефон и WhatsApp.** Заменить `+971 50 000 0000` во всех файлах (поиск по `971500000000`): ссылки `wa.me` в 4 страницах и в `js/script.js` (отправка формы).
- [ ] **Соцсети.** Ссылки Instagram и TikTok сейчас пустые (`href="#"`) — вставить реальные профили или временно убрать кнопки.
- [ ] **Проверить адрес, часы работы, email** (футер всех страниц + contacts.html).
- [ ] **Вычитать тексты**: цены в тарифах, условия залога, FAQ — всё должно соответствовать реальным условиям аренды.

## 2. Домен и хостинг

- [ ] Купить домен (например, `dressrentdubai.com` / `.ae`).
- [ ] Сайт полностью статический — бесплатного хостинга достаточно: **GitHub Pages**, **Netlify** или **Vercel** (перетащить папку — сайт онлайн). HTTPS включается автоматически.
- [ ] Подключить домен к хостингу, проверить редирект `www` → без `www`.

## 3. SEO и находимость

- [ ] Title и description уже прописаны на всех 4 страницах — при смене позиционирования обновить.
- [ ] Добавить **Open Graph** разметку (`og:title`, `og:description`, `og:image` — красивое фото 1200×630) для превью в WhatsApp/Instagram.
- [ ] Добавить **schema.org LocalBusiness** (JSON-LD): название, адрес, часы, телефон, рейтинг — даёт расширенный сниппет в Google.
- [ ] Создать `sitemap.xml` и `robots.txt`.
- [ ] Зарегистрировать **Google Business Profile** (карточка на картах Google — критично для локального бизнеса в Дубае) и добавить карту на страницу контактов.
- [ ] Отправить сайт в Google Search Console.

## 4. Аналитика и каналы связи

- [ ] Подключить **GA4** и/или **Яндекс.Метрику**.
- [ ] Настроить цели: клик по WhatsApp, отправка формы, клик по телефону.
- [ ] Перевести номер на **WhatsApp Business**: каталог, автоответ, быстрые ответы («цены», «адрес», «как забронировать»).
- [ ] Проверить, что заявка из формы корректно открывает WhatsApp с заполненным текстом на реальном номере.

## 5. Качество и производительность

- [ ] Прогнать **Lighthouse** (цель: 90+ по всем метрикам). Сайт лёгкий, но после замены фото — сжать их в **WebP**, ширина 640–800px для карточек.
- [ ] Проверить на реальных устройствах: iPhone Safari, Android Chrome — особенно свайп галереи и форму.
- [ ] Заменить emoji-favicon на настоящий набор (favicon.ico + apple-touch-icon) — генерируется на realfavicongenerator.net.
- [ ] Проверить все ссылки (нет битых, нет оставшихся `#`).

## 6. Юридическое

- [ ] Страница **политики конфиденциальности** (форма собирает имя и телефон).
- [ ] Публичные **условия аренды**: залог, ответственность за повреждения, сроки возврата — можно оформить страницей или PDF.

## 7. После запуска (рост)

- [ ] **EN-версия** сайта (основная аудитория Дубая англоязычная), затем — арабская (RTL).
- [ ] Онлайн-календарь доступности платьев / бронирование дат.
- [ ] Сбор отзывов Google и виджет отзывов на сайте.
- [ ] Instagram-контент: рилсы с примерок → трафик на сайт.
- [ ] Расширение галереи: страница каждого платья (размеры, наличие по датам, несколько фото).

---

### Техническая справка

| Что | Где |
|---|---|
| Каталог галереи (названия, цены, фото) | `js/script.js`, массив `looks` |
| Цвета и стиль | `css/style.css`, переменные в `:root` |
| Номер WhatsApp | все `*.html` + `js/script.js` (поиск `971500000000`) |
| Страницы | `index.html`, `about.html`, `pricing.html`, `contacts.html` |

Сайт не требует сборки и серверной части — любой хостинг статики подходит.
