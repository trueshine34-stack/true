# PLO Vault — выгрузка рук из PokerCraft (GGPoker) на Android

Приложение забирает **вашу собственную** историю рук из PokerCraft, складывает её в
локальную базу на телефоне и считает статистику по Rush & Cash PLO4 на всех лимитах.
Игровой клиент оно не трогает — это автоматизация той же кнопки «скачать историю рук»,
которую вы нажимаете руками.

## Что умеет

- **Встроенный браузер PokerCraft** — вы входите в свой аккаунт GGPoker как обычно,
  куки живут внутри приложения.
- **Режим «Обучение»** — пока вы один раз выгружаете историю вручную, приложение
  перехватывает сетевой запрос выгрузки и сохраняет его как «рецепт».
- **Автосинхронизация** — дальше приложение само повторяет этот запрос по расписанию
  (каждые N часов), подставляя свежие даты, скачивает файл и разбирает раздачи.
  Дубликаты отсеиваются по номеру раздачи.
- **Импорт файла** — если удобнее скачать zip/txt вручную, его можно скормить приложению
  кнопкой «Импорт файла» или «Поделиться → PLO Vault» из браузера либо файлового
  менеджера. Этот путь работает всегда, даже если токен передать не удаётся.
- **Парсер GGPoker HH** — PLO4/PLO5/PLO6 и холдем, Rush & Cash определяется по номеру
  раздачи и названию стола, тип игры — ещё и по количеству карманных карт (не сломается,
  если GG поменяет подпись игры). Учитываются рейк, джекпот-сборы, All-in Cash Out,
  run-it-twice, анте и стрэддлы.
- **Статистика**: результат в $ и bb, bb/100, VPIP, PFR, 3-бет, «видел флоп», WTSD, W$SD,
  рейк — в целом, по лимитам, по позициям и по месяцам, плюс график в bb.
- **Экспорт**: CSV по раздачам (для Excel/Python/BI) и zip с сырыми HH-файлами
  (для PokerTracker / Hand2Note).

## Установка

APK собирается локально или в GitHub Actions (вкладка Actions → Build APK → артефакт
`plovault-apk`). На телефоне: разрешить установку из неизвестных источников →
поставить `app-release.apk`. Минимум Android 8.0.

Локальная сборка:

```bash
cd pokercraft-sync
./gradlew :app:assembleRelease      # app/build/outputs/apk/release/app-release.apk
./gradlew :parser:test :app:testDebugUnitTest
```

## Первый запуск — 4 шага

1. В клиенте GGPoker откройте PokerCraft и передайте ссылку в приложение — **сразу**, токен
   живёт считанные минуты. Два способа:
   - «Поделиться» / «Открыть в браузере» → в списке приложений выбрать **PLO Vault**:
     ссылка откроется в приложении автоматически (приложение зарегистрировано как
     обработчик адресов `my.pokercraft.com`);
   - скопировать адрес вида `https://my.pokercraft.com/?token=…&lang=ru` и нажать
     **«Вставить и открыть»** на вкладке Синхро.

   Токен сохраняется только на телефоне и показывается замаскированным.
2. Откроется ваш кабинет PokerCraft. Тумблер «Обучение» уже включён.
3. Зайдите в историю рук, выберите Rush & Cash / PLO и нужный период, нажмите скачивание
   как обычно. Файл приложение подхватит и разберёт сразу, а запрос запомнит.
4. Нажмите **«Сохранить рецепт»** → вернитесь назад → включите **Автосинхронизацию**.

Дальше руки подтягиваются сами.

### Когда токен истечёт

Признак — страница «ОТКАЗАНО В ДОСТУПЕ / session has expired». Приложение распознаёт её
и показывает кнопки «Вставить и открыть» и «Сбросить куки и открыть» прямо поверх
браузера. Автосинхронизация в этом случае присылает уведомление с HTTP 401/403 и просьбой
вставить свежую ссылку. Достаточно скопировать
новый адрес PokerCraft из клиента и вставить его в то же поле — **обучение повторять не
нужно**: в рецепте токен хранится как плейсхолдер `{{TOKEN}}` и подставляется свежим при
каждой выгрузке. То же касается токена в заголовке `Authorization`.

## Почему «рецепт», а не зашитые адреса

У PokerCraft нет публичного API, а внутренние адреса выгрузки меняются и отличаются по
лицензиям/доменам. Поэтому приложение не угадывает запрос, а **записывает ваш настоящий**
и повторяет его. Если GG что-то поменяет — достаточно один раз пройти «Обучение» заново,
пересобирать приложение не нужно.

Подстановку дат приложение распознаёт само: `2024-03-12`, `2024/03/12`, `20240312`,
epoch в секундах и миллисекундах. Что именно записано — видно в Настройки → «Рецепт выгрузки».

## Куда всё складывается

- База раздач: `plovault.db` во внутренней памяти приложения (разобранные поля, без сырого текста).
- Сырые файлы выгрузки: `files/hh_raw/` — по ним можно в любой момент пересобрать базу
  кнопкой «Переразобрать сырые файлы» (например, после улучшения парсера).

## Ограничения, о которых честно

- Адреса выгрузки у PokerCraft закрытые, поэтому режим обучения — обязательный первый шаг;
  «из коробки» приложение не знает, куда стучаться.
- Автосинхронизация работает, пока жив токен из ссылки (и куки сессии). Как долго —
  зависит от аккаунта и региона; при истечении приложение просит вставить свежую ссылку,
  а не молчит.
- Токен — это доступ к вашему кабинету. Он хранится в приватных настройках приложения на
  телефоне, никуда не отправляется, кроме самого PokerCraft, и не попадает в репозиторий.
- Cash Out учитывается эвристикой: выплата по кэшауту засчитывается, если банк в этой
  раздаче не собран обычным способом.
- Это ваша собственная история рук и ваш собственный экспорт. Приложение не читает память
  клиента, не подсказывает в игре и не собирает чужие данные.

## Структура проекта

```
pokercraft-sync/
├── parser/                 # чистый Kotlin: парсер HH, статистика, CSV (+8 тестов)
└── app/                    # Android: WebView-перехват, база, автосинк, UI на Compose
    └── src/main/java/com/plovault/sync/
        ├── web/            # перехват запросов и blob-загрузок внутри страницы
        ├── data/           # SQLite, настройки, рецепт выгрузки, импорт zip/txt/json
        ├── net/            # скачивание с куками WebView
        ├── sync/           # WorkManager: автосинхронизация и уведомления
        └── ui/             # экраны: Синхро, Руки, Статистика, Настройки
```
