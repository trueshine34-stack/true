# instaclean

Быстрая чистка подписок в Instagram: находит всех, на кого вы подписаны, но кто **ни разу
не поставил лайк ни одной вашей публикации** — и отписывается от них.

Лайки из **архивных публикаций** учитываются наравне с обычными: если человек лайкнул только
тот пост, который вы потом убрали в архив, он считается активным и в отписку не попадёт.

## Сначала прочитайте это

Официального API для отписок у Instagram нет, поэтому инструмент работает через приватный
мобильный API (библиотека `instagrapi`), как это делает само приложение. Такая автоматизация
противоречит правилам Instagram: при слишком быстрой работе аккаунт может получить временное
ограничение действий, а в худшем случае — блокировку. Чтобы этого не случилось:

* по умолчанию отписка идёт порциями: **50 аккаунтов за запуск**, пауза 25–70 секунд между ними;
* при первом же сигнале «слишком часто» программа сама останавливается;
* прогресс сохраняется, поэтому спокойно запускайте команду раз в день, пока список не кончится;
* **сначала всегда пробный прогон** — без флага `--execute` никто не отписывается.

Используйте только на своём аккаунте.

## Установка

```bash
cd instaclean
python3 -m pip install -r requirements.txt
```

Либо поставить как команду `instaclean`:

```bash
python3 -m pip install .
```

Ниже везде можно писать `instaclean …` вместо `python3 -m instaclean …`.

## Быстрый старт

```bash
export IG_USERNAME=ваш_логин           # пароль спросят в терминале

python3 -m instaclean login            # вход, сессия сохранится
python3 -m instaclean scan             # собрать посты (с архивом), лайки, подписки
python3 -m instaclean unfollow         # пробный прогон: показать, кого отпишем
python3 -m instaclean unfollow --execute   # отписаться (50 за раз)
```

Повторяйте последнюю команду раз в день, пока не останется кандидатов. Уже обработанные
аккаунты второй раз не трогаются.

Всё одной командой (сбор + отчёт + отписка):

```bash
python3 -m instaclean clean --execute
```

## Команды

| Команда | Что делает |
|---|---|
| `login` | вход, сохранение сессии (пароль на диск не пишется) |
| `scan` | собирает ваши публикации (включая архив), лайкнувших по каждой и список подписок |
| `report` | показывает отчёт и пишет `candidates.csv` по уже собранным данным, без сети |
| `unfollow` | отписка от кандидатов; без `--execute` — только показывает список |
| `clean` | `scan` + отчёт + отписка одной командой |
| `whitelist --add ...` | список тех, кого не трогать никогда |

Полезные флаги:

* `--with-comments` — считать активными и тех, кто комментировал, а не только лайкал;
* `--limit N` — сколько отписок за один запуск (`0` — без ограничения, не рекомендуется);
* `--delay МИН МАКС` — пауза между отписками в секундах (по умолчанию `25 70`);
* `--scan-delay МИН МАКС` — пауза между запросами лайков при сборе (по умолчанию `1.5 4`);
* `--no-archive` — не читать архивные публикации;
* `--refresh` — перечитать посты и подписки, игнорируя кеш;
* `--code 123456` — код двухфакторной аутентификации;
* `--proxy http://user:pass@host:port` — работать через прокси.

## Белый список

Чтобы кто-то никогда не попал в отписку:

```bash
python3 -m instaclean whitelist --add mom best_friend some_brand
```

Файл лежит в `~/.instaclean/<логин>/whitelist.txt`, его можно править руками
(один логин в строке, `#` — комментарий).

## Где хранятся данные

Всё в `~/.instaclean/<логин>/` (папку можно переопределить переменной `INSTACLEAN_HOME`):

| Файл | Что внутри |
|---|---|
| `session.json` | токен сессии (права `600`), пароль не сохраняется |
| `medias.json` | список ваших публикаций, включая архивные |
| `likers.json` | кто лайкал каждую публикацию (кеш, пополняется по ходу) |
| `following.json` | список ваших подписок |
| `candidates.csv` | кандидаты на отписку — можно открыть и проверить глазами |
| `unfollowed.csv` | журнал отписок, по нему же работает докат при повторном запуске |
| `whitelist.txt` | кого не трогать |

Сбор лайков можно прерывать по Ctrl+C: всё уже собранное остаётся в кеше, следующий запуск
продолжит с того же места. Чтобы пересобрать заново — удалите нужный файл кеша или
запустите `scan --refresh` (для постов и подписок).

## Ограничения, о которых стоит знать

* **Посты с большим числом лайков.** Instagram отдаёт только часть списка лайкнувших
  (примерно первую тысячу). Если такое встретилось, программа пишет об этом в отчёте:
  часть людей может попасть в кандидаты ошибочно — перед отпиской просмотрите
  `candidates.csv`.
* **Лайки на историях и реакции в директе не считаются** — только лайки на публикациях.
* **Архив.** Архивные публикации читаются через приватный эндпоинт `feed/only_me_feed/`.
  Если Instagram его не отдаст, программа не упадёт, а честно предупредит, что лайки из
  архива не учтены.
* Запросы к Instagram намеренно медленные — это не зависание.

## Тесты

Логика сбора, подсчёта кандидатов и отписки покрыта тестами на поддельном клиенте,
без обращений к Instagram:

```bash
python3 -m unittest discover -s tests -v
```
