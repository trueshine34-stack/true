# Poker Tracker

Android-приложение для лайв- и онлайн-сессий: будильник каждые 15 минут спрашивает результат
в больших блайндах, считает общий баланс и время за столом, запускает пятиминутный перерыв.

## Что делает

**Будильник каждые 15 минут.** Пока идёт сессия, приложение точным будильником
(`setExactAndAllowWhileIdle`) поднимает экран с вопросом «Какой результат?». Звонит как
настоящий будильник: зацикленный сигнал в канале `USAGE_ALARM`, вибрация, полноэкранное
уведомление поверх локскрина. Сам замолкает через 90 секунд, чтобы не звонить в пустой комнате.
Интервал переключается на 5 / 10 / 15 / 20 / 30 / 45 / 60 минут.

**Ввод результата.** Плюс-минус с шагом, который растёт вместе с числом (0,5 → 1 → 5),
быстрые фишки от −20 до +40 BB и поле для точного значения. Отсюда же можно сразу уйти
на перерыв или пропустить чек-ин.

**Перерыв 5 минут.** Кольцевой отсчёт, кнопка «+1 мин», досрочный возврат за стол.
На время перерыва счётчик сессии встаёт на паузу, а вопросы замолкают — BB/час не размывается.
Когда таймер дойдёт до нуля, будильник позовёт обратно.

**Счётчики.** Чистое время за столом без пауз и перерывов, баланс в BB, BB/час, число чек-инов,
лучший и худший интервал, столбиковый график последних 24 записей, история завершённых сессий.
Всё это дублируется в постоянном уведомлении с кнопками «Записать BB» и «Пауза».

Записи и история хранятся локально в `SharedPreferences`. Сети приложение не касается.

## Установка

Готовый файл — `app/build/outputs/apk/release/app-release.apk`.

1. Скинуть APK на телефон и открыть его.
2. Разрешить установку из неизвестных источников, если система спросит.
3. При первом запуске выдать разрешения — приложение само подсветит красной плашкой то,
   чего не хватает, и по нажатию откроет нужный экран настроек:
   - уведомления (Android 13+);
   - точные будильники (Android 12+);
   - полноэкранные уведомления (Android 14+) — без них вопрос не будет будить экран;
   - отключение экономии батареи — иначе система усыпит будильник.

APK подписан отладочным ключом из `keystore/`. Для Play Store нужен свой ключ.

## Сборка

```bash
export ANDROID_HOME=/path/to/android-sdk   # нужны platforms;android-35 и build-tools;35.0.0
./gradlew assembleRelease
```

Java 17+, Gradle 8.9+. Внешних зависимостей нет — только Android SDK,
поэтому сборка не тянет ничего из сети после установки SDK.

## Как устроено

| Файл | Отвечает за |
|---|---|
| `Prefs.java` | всё состояние сессии: старт, паузы, записи, история, производные метрики |
| `AlarmScheduler.java` | точные будильники чек-ина и конца перерыва, откат на неточные при запрете |
| `AlarmReceiver.java` | приём будильника; сразу ставит следующий, чтобы цепочка не оборвалась |
| `AlarmService.java` | звонок: зацикленный сигнал, вибрация, полноэкранное уведомление |
| `SessionService.java` | foreground-сервис с живым таймером в уведомлении |
| `MainActivity.java` | главный экран, статистика, разрешения |
| `CheckInActivity.java` | ввод результата и экран «перерыв окончен» |
| `BreakActivity.java` | кольцевой отсчёт перерыва |
| `RingView.java`, `BarsView.java` | кольцо отсчёта и график результатов |

Минимальная версия Android — 7.0 (API 24), целевая — Android 15 (API 35).
