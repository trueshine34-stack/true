# TG Poster — автопостинг в Telegram с генерацией через DeepSeek

Android-приложение (APK), которое само пишет и публикует посты в ваших Telegram-каналах:
несколько ботов-аккаунтов, сколько угодно каналов, у каждого канала своя инструкция для
нейросети, свои рубрики, свои источники и своё расписание.

Готовый APK: [`release/tgposter-1.0.1.apk`](release/tgposter-1.0.1.apk) (~1.9 МБ, Android 8.0+).

## Что умеет

**Аккаунты**
- Несколько ботов Telegram одновременно, у каждого свой токен.
- Проверка токена через `getMe`, проверка прав в канале через `getChatMember`.
- Отдельный переключатель «активен» — можно приостановить весь бот целиком.

**Каналы**
- Сколько угодно каналов на каждого бота, каждый со своими настройками.
- Собственная инструкция для нейросети: о чём канал, для кого, структура поста, чего избегать.
- Мастер инструкции: коротко описываете канал — DeepSeek пишет полноценное ТЗ редактору.
- Стиль: аудитория, тон, язык, диапазон длины, уровень эмодзи.
- Обвязка поста: хэштеги, призыв к действию, подпись, запрещённые темы, доп. правила.
- Часовой пояс на канал — расписание считается по местному времени канала, а не телефона.
- Настройки публикации: разметка (HTML / MarkdownV2 / без), скрытие превью ссылок,
  беззвучная отправка, запрет пересылки, автозакрепление.
- Модель и температура — можно переопределить для конкретного канала.

**Контент**
- Генерация через DeepSeek (`deepseek-chat` или `deepseek-reasoner`).
- Рубрики с весами: чем больше вес и чем дольше рубрика не выпадала, тем выше шанс —
  канал не залипает на одной теме.
- Память последних тем: модель получает список того, что уже было, и не повторяется.
- RSS-источники как фактура для новостных каналов и дайджестов.
- Анализ канала: DeepSeek разбирает, что публиковалось, и предлагает 10 тем и набор рубрик.
- Разовые посты вне расписания с произвольным заданием.
- Редактирование и перегенерация любого поста до публикации.

**Публикация**
- Расписания: по конкретным временам или с интервалом внутри окна, по дням недели,
  со случайным разбросом ±N минут.
- Несколько расписаний на канал (например, будни в 10:00 и 19:00 плюс выходные в 12:00).
- Тексты генерируются заранее (по умолчанию за 30 минут), чтобы в момент публикации
  не зависеть от сети.
- Режим модерации: пост ждёт вашего подтверждения в очереди.
- Картинка по URL — Telegram загружает её сам.
- Соблюдение лимитов Telegram: длина сообщения, длина подписи, частота отправки,
  обработка `429 retry_after`.

**Эксплуатация**
- Главный рубильник «Автопилот» — останавливает всё одним переключателем.
- Уведомления об ошибках и о постах на модерации.
- Журнал событий с экспортом.
- Автоочистка старых постов и логов.
- Экспорт/импорт всей конфигурации в JSON.
- Работа только по Wi-Fi (опционально).
- Восстановление расписания после перезагрузки телефона.

## Как это работает внутри

```
                    ┌──────────────────────────────────────┐
                    │  AutopilotWorker (каждые 15 минут)   │
                    └───────────────┬──────────────────────┘
                                    │
        ┌───────────────┬───────────┴─────────┬──────────────────┐
        ▼               ▼                     ▼                  ▼
   QueuePlanner    ContentGenerator      Publisher        очистка старого
   расписание →    DeepSeek + RSS +      Telegram         (посты, логи)
   слоты в БД      рубрика + история     Bot API
```

Жизненный цикл поста:

```
QUEUED ──генерация──► READY ──────время публикации──────► PUBLISHED
   │                    ▲                                     
   │                    │ подтверждение                       
   └──генерация──► NEEDS_APPROVAL                             
                                                              
   при ошибке: FAILED (можно повторить)                       
   слот просрочен > 6 ч: SKIPPED                              
```

1. **Планировщик** раскладывает расписания в конкретные моменты публикации на 36 часов
   вперёд и создаёт заготовки постов в базе. Слоты считаются детерминированно (даже
   случайный разброс задаётся сидом от id расписания и времени слота), а уникальный
   индекс `(канал, расписание, время)` не даёт создать дубль при повторном проходе.
2. **Генератор** за N минут до публикации собирает промпт: системная часть из настроек
   канала + рубрика + свежие записи из RSS + список последних тем. DeepSeek отвечает в
   JSON (`topic`, `text`, `hashtags`, `image_prompt`), текст очищается до безопасного
   подмножества HTML и сохраняется.
3. **Публикатор** отправляет пост в назначенную минуту. Для точности на каждый ближайший
   пост ставится отдельная задача с точной задержкой, а периодический проход раз в 15 минут
   работает страховкой — если телефон спал, пост уйдёт при первом же пробуждении.

**Важно про точность времени.** Android не даёт фоновым задачам гарантии «секунда в
секунду»: в глубоком сне (Doze) публикация может сдвинуться на несколько минут. Для
автопостинга это обычно незаметно, а разброс ±минут делает сдвиг вообще неотличимым.
Чтобы сдвиг был минимальным — отключите оптимизацию батареи для приложения
(Настройки → Автопилот → «Настройки батареи»).

## Установка APK

1. Скачайте [`release/tgposter-1.0.1.apk`](release/tgposter-1.0.1.apk) на телефон.
2. Откройте файл — Android попросит разрешить установку из этого источника, разрешите.
3. При первом запуске разрешите уведомления (иначе не увидите сообщений об ошибках).

Требования: Android 8.0 (API 26) и выше.

APK подписан ключом разработки из этого репозитория (`signing/dev-signing.jks`, пароль
`tgposter`) — это сделано специально, чтобы новые сборки ставились поверх старых как
обновление. Ключ не секретный и годится только для личного использования: для публикации
в сторах заведите собственный (см. [Сборка из исходников](#сборка-из-исходников)).

## Первый запуск: 5 шагов

### 1. Создайте бота

В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и
username. BotFather пришлёт токен вида `1234567890:AAH...`.

### 2. Добавьте бота в канал

Канал → «Управление каналом» → «Администраторы» → «Добавить администратора» → найдите
своего бота → обязательно включите право **«Публикация сообщений»**.

### 3. Внесите бота в приложение

Обзор → «Телеграм-аккаунты» → **+** → вставьте токен. Приложение сразу проверит его и
покажет username бота.

### 4. Добавьте ключ DeepSeek

Получите ключ на [platform.deepseek.com](https://platform.deepseek.com) → API keys.
В приложении: Настройки → DeepSeek → «Добавить ключ» → «Проверить».

### 5. Заведите канал

Каналы → **+**:
- **Название** — любое, для себя.
- **@username или chat_id** — для публичного канала `@mychannel`. Для приватного нужен
  числовой id вида `-1001234567890`: перешлите любой пост из канала боту
  [@userinfobot](https://t.me/userinfobot), он покажет id.
- **Бот-аккаунт** — выберите бота из шага 3.
- **Часовой пояс** — по нему считается расписание.

Нажмите **«Проверить доступ»** — приложение убедится, что бот видит канал и может
публиковать. Потом **«Тест-пост»** — придёт тестовое сообщение.

Дальше — вкладка «Контент» (инструкция), вкладка «Расписание» (когда публиковать),
«Сохранить». Убедитесь, что на экране «Обзор» включён **Автопилот**.

## Настройка канала

Экран канала разбит на вкладки.

### Основное
Название, chat_id, бот, часовой пояс, активность, кнопки проверки.

### Контент

**Инструкция канала** — главный текст, по которому пишутся посты. Пример:

```
Канал про личные финансы для тех, кто только начинает. Пишем простым языком,
без биржевого жаргона и без обещаний доходности.

Структура поста: цепляющая первая строка (не вопрос), затем суть в 2–3 абзацах,
затем один практический шаг, который читатель может сделать сегодня.

Никаких «в современном мире», «не секрет, что». Не рекомендуем конкретные
брокеров и тикеры. Не обещаем прибыль. Цифры — только общеизвестные.
```

Если писать лень — кнопка **«Сгенерировать инструкцию через DeepSeek»**: опишите канал
одной фразой, модель развернёт это в полноценное ТЗ, которое потом можно поправить.

**Стиль**: аудитория, тон, язык, минимум и максимум символов, уровень эмодзи.

**Обвязка поста** — то, что дописывается к каждому посту:
- *Хэштеги* — фиксированный набор. Оставьте пустым, чтобы модель подбирала их сама.
- *Призыв к действию* — например «Подписывайтесь, если полезно».
- *Подпись* — например «— Ваш канал про финансы».
- *Запрещённые темы* — жёсткий стоп-лист.
- *Дополнительные правила* — всё остальное.

**Модель**: `deepseek-chat` быстрее и дешевле, `deepseek-reasoner` рассуждает дольше и
пишет глубже. Температура ниже 0.7 — суше и предсказуемее, выше 1.0 — креативнее.

### Публикация
Разметка, превью ссылок, беззвучность, запрет пересылки, автозакрепление, модерация,
за сколько минут генерировать текст заранее. Здесь же — «Создать пост вручную» и
«Проанализировать канал».

## Расписание

Два режима:

**По времени** — список конкретных моментов: `09:00, 14:30, 20:00`.
Плюс дни недели: например только Пн–Пт.

**С интервалом** — каждые N минут внутри окна: с 09:00 до 22:00 каждые 180 минут.

Общее для обоих:
- **Дни недели** — чипы Пн…Вс.
- **Разброс ±минут** — случайный сдвиг. При 15 минутах пост, назначенный на 10:00,
  выйдет где-то между 09:45 и 10:15. Сдвиг детерминированный: он не «пересчитывается»
  при каждом проходе планировщика, поэтому дублей не возникает.

Расписаний на канал может быть несколько — они складываются. Под каждым показано
человеческое описание, время следующего слота и оценка «постов в неделю».

## Рубрики

Рубрика — тематический блок со своей подсказкой. Перед каждым постом выбирается одна.

Пример для канала про финансы:

| Рубрика | Подсказка | Вес |
|---|---|---|
| Разбор инструмента | Разбери один финансовый инструмент: что это, кому подходит, риски | 3 |
| Ошибка новичка | Опиши одну типичную ошибку и как её избежать | 2 |
| Мини-практика | Дай одно упражнение на 10 минут для наведения порядка в финансах | 1 |

Вес влияет на частоту. Дополнительно учитывается, когда рубрика выпадала в последний
раз: чем дольше не использовалась, тем выше шанс. Так канал не залипает на одной теме.

Без рубрик тоже работает — модель берёт тему сама, опираясь на инструкцию канала.

## Источники (RSS)

Ссылки на RSS/Atom-ленты. Перед генерацией приложение скачивает свежие записи и отдаёт
их модели как фактуру: «вот что произошло, напиши пост на основе этого». Полезно для
новостных каналов и дайджестов; для вечнозелёного контента можно не заполнять.

Кнопка «Проверить» показывает, сколько записей удалось загрузить и заголовок первой.

## Очередь и модерация

Экран «Очередь» с фильтрами: активные, на модерации, опубликованные, проблемы.

Для каждого поста доступны: сгенерировать сейчас, опубликовать сейчас, подтвердить
(в режиме модерации), повторить после ошибки, отменить, удалить, открыть.

На экране поста можно: отредактировать текст вручную, перегенерировать с уточнением
(«сделай короче и без вопроса в конце»), подставить URL картинки, перенести время
публикации, посмотреть точный запрос, который ушёл в модель.

**Режим модерации** (настраивается на канале) — пост генерируется заранее, приходит
уведомление, и в канал он уходит только после вашего подтверждения. Полезно, пока вы
настраиваете инструкцию и не доверяете автопилоту полностью.

## Резервная копия

Настройки → Резервная копия → **Экспорт**: JSON со всеми аккаунтами, каналами,
инструкциями, расписаниями, рубриками и источниками.

Переключатель **«Включить ключи в файл»** добавляет в JSON токены ботов и ключ DeepSeek.
По умолчанию выключен. Если включили — храните файл как пароль: он даёт полный доступ к
вашим каналам.

**Импорт** добавляет данные к существующим, ничего не удаляя.

## Безопасность ключей

- Токены ботов и ключ DeepSeek шифруются AES-256/GCM ключом из **Android Keystore** —
  сам ключ шифрования не покидает устройство и не извлекается из него.
- В базе данных лежат только ссылки на секреты, не сами секреты.
- Файл с секретами исключён из облачного бэкапа Android и из переноса на новое
  устройство (ключ шифрования всё равно не переносится).
- Ключи не отправляются никуда, кроме `api.telegram.org` и `api.deepseek.com`.

При смене телефона перенесите конфигурацию через экспорт с включёнными ключами.

## Ограничения, о которых надо знать

**Работа идёт через Bot API, а не через личные аккаунты.** «Аккаунт» в приложении — это
бот. Публиковать от имени вашего личного аккаунта Telegram нельзя: для этого нужен MTProto
и авторизация по номеру телефона, что и технически тяжелее, и рискованно для аккаунта.
Для каналов это не ограничение — посты в канале и так выходят от имени канала.

**Bot API не отдаёт список каналов бота.** Поэтому канал добавляется вручную по
`@username` или `chat_id`, а приложение проверяет доступ.

**Лимиты Telegram.** Не чаще ~1 сообщения в секунду в один чат и ~30 в секунду суммарно.
Приложение выдерживает паузы (1.1 с глобально, 3.5 с на чат) и корректно обрабатывает
`429 retry_after`. Текст длиннее 4096 символов разбивается на части по абзацам; подпись
к фото длиннее 1024 символов уходит отдельным сообщением.

**Разметка.** Модель иногда возвращает markdown или теги, которых Telegram не понимает, —
такой пост API отклонил бы целиком. Приложение приводит текст к безопасному подмножеству
HTML (`<b> <i> <u> <s> <code> <pre> <blockquote> <a>`), закрывает непарные теги и
экранирует всё остальное.

**Точность времени** — см. [Как это работает внутри](#как-это-работает-внутри).

**Стоимость DeepSeek** приложение не считает — следите за расходом в личном кабинете.
Ориентир: один пост при лимите 1600 токенов — это примерно 2–3 тысячи токенов вместе с
промптом.

**Картинки не генерируются** — DeepSeek не умеет в изображения. Модель возвращает
`image_prompt` (описание картинки на английском), его можно скормить любому генератору
и вставить готовый URL в пост вручную.

## Сборка из исходников

Нужны JDK 17+ и Android SDK (compileSdk 35, build-tools 35.0.0).

```bash
cd tgposter

# отладочная сборка
./gradlew :app:assembleDebug

# release (минифицированный)
./gradlew :app:assembleRelease

# тесты
./gradlew :app:testDebugUnitTest
```

APK появится в `app/build/outputs/apk/<тип>/`.

Если Gradle не видит SDK — создайте `local.properties`:

```properties
sdk.dir=/путь/к/android-sdk
```

### Свой ключ подписи

```bash
keytool -genkeypair -v -keystore my-release.jks -alias myapp \
  -keyalg RSA -keysize 2048 -validity 10000
cp keystore.properties.example keystore.properties
# впишите путь и пароли
```

`keystore.properties` и `*.jks` уже в `.gitignore`. Если файл есть, release-сборка
подписывается им; иначе используется ключ разработки из репозитория.

### CI

`.github/workflows/tgposter-android.yml` на каждый push в `tgposter/**` прогоняет тесты,
собирает release-APK и выкладывает его как артефакт сборки.

## Что делать, если

| Симптом | Причина и решение |
|---|---|
| «Не задан API-ключ DeepSeek» | Настройки → DeepSeek → «Добавить ключ». |
| «chat not found» | Неверный chat_id, либо бот не добавлен в канал. Проверьте кнопкой «Проверить доступ». |
| «not enough rights» | У бота нет права «Публикация сообщений» в настройках администраторов канала. |
| Посты не создаются | Проверьте: включён Автопилот, включён канал, включён бот, у канала есть хотя бы одно включённое расписание с выбранными днями недели. |
| Посты выходят с опозданием | Отключите оптимизацию батареи: Настройки → Автопилот → «Настройки батареи». |
| Посты выходят пустыми / странными | Инструкция канала слишком общая. Опишите структуру поста и запреты конкретнее, снизьте температуру. |
| Посты повторяются | Добавьте рубрики и увеличьте «Помнить последних тем». |
| «can't parse entities» | Редкий случай экзотической разметки. Переключите канал на разметку `NONE` и перегенерируйте пост. |
| Ошибка 429 | Слишком частые публикации в один канал. Приложение само подождёт и повторит; если повторяется — увеличьте интервалы. |
| Всё сломалось | Журнал событий (Обзор → «Журнал событий») → «Экспорт» — там точная причина. |
