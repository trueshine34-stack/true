# true

Два Android-приложения для автопостинга с генерацией контента через DeepSeek.

| Приложение | Что делает | APK |
|---|---|---|
| [**tgposter**](tgposter) | Автопостинг в Telegram-каналах: несколько ботов, много каналов, инструкции и расписание под каждый канал | [`tgposter/release/tgposter-1.0.1.apk`](tgposter/release/tgposter-1.0.1.apk) |
| [**threadsposter**](threadsposter) | Threads: автопостинг, поиск чужих постов по ключевым словам и осмысленные ответы на них и на свои комментарии | [`threadsposter/release/threadsposter-1.0.0.apk`](threadsposter/release/threadsposter-1.0.0.apk) |

Приложения независимы, ставятся рядом и не конфликтуют. Подробности — в README каждого.

Ещё в репозитории: [dressrentdubai](dressrentdubai) — лендинг студии аренды платьев.
